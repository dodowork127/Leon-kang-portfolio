# Leon Kang Portfolio

가상의 다방면 천재 예술가 **강리온 / Leon Kang**를 위한 정적 포트폴리오 웹사이트입니다.

## 구성
- `index.html`
- `assets/css/styles.css`
- `assets/js/app.js`
- `assets/img/*` : 사이트에 쓰이는 이미지 자산
- `assets/source/*` : 원본 AI 생성 보드 2장

## 특징
- 약 10개 섹션으로 구성된 단일 페이지
- 고정 헤더, 스크롤 진행 바, 인터섹션 기반 reveal 애니메이션
- 필터 가능한 대표작 카드
- 작품 상세 모달
- 정적 환경에서도 동작하는 문의 템플릿 클립보드 복사 기능
- 모든 비주얼은 AI 생성 보드에서 추출/재구성

## 실행
브라우저에서 `index.html`을 열면 됩니다.

## 메모
추가 단일 컷 생성은 세션 중 이미지 생성 rate limit에 걸려,
이번 버전은 이미 생성된 비주얼 보드 2장을 크롭/재구성하여 완성했습니다.
